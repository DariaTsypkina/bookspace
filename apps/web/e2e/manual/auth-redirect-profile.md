# Auth: редирект /login|/register → /u/[slug] (bd-957.1)

Ручной чеклист для человека. Агент гоняет автотесты отдельно.

## Перед проверкой

- [ ] `docker compose up -d` (Postgres + Redis)
- [ ] API на `:8000`, web на `:3000`
- [ ] Миграции применены (`pnpm --filter api prisma migrate deploy`)

## Сценарии

1. **Гость — формы**
   - [ ] Открыть `/login` → заголовок «Вход», поля Email/Пароль, кнопка «Войти»
   - [ ] Открыть `/register` → «Регистрация», форма видна

2. **Регистрация и вход**
   - [ ] Зарегистрировать нового пользователя
   - [ ] Войти → сессия установлена (нет ошибок)

3. **Редирект авторизованного**
   - [ ] Будучи в сессии, открыть `/login` → попадаете на `/u/<ваш-slug>` без формы входа
   - [ ] Открыть `/register` → тот же `/u/<ваш-slug>` без формы регистрации
   - [ ] На stub: заголовок «Профиль», текст про скорый профиль, виден slug

4. **Mobile**
   - [ ] Повторить п.1 и п.3 в узком viewport (или Chrome device Pixel 7)

## Не регрессия

- [ ] Cookie `session` по-прежнему httpOnly на API-origin после login
- [ ] Слабый пароль / дубликат email / неверный логин — по-прежнему ошибки на русском
