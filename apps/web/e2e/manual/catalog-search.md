# Ручная проверка: Поиск по каталогу (bd-6v0.1)

## Предусловия

- Postgres + API + Web запущены локально
- Выполнен seed: `pnpm --filter api prisma:seed`

## Сценарии

### Пустой поиск

- [ ] Открыть `/search` без `q`
- [ ] Видны подсказки, список результатов пуст
