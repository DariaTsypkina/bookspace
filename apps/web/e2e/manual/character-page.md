# Ручной чеклист: карточка персонажа

## Предусловия

- Локально подняты Postgres, API (`:8000`), web (`:3000`)
- Выполнен `pnpm --filter api prisma:seed`

## Гость без cookie

1. Открыть `/characters/garri-potter`
2. Убедиться: заголовок «Гарри Поттер», оригинальное имя, секция «Книги появления» с ссылкой на книгу
3. Секция «Связи»: видно предупреждение «Могут быть спойлеры», ссылки на других персонажей скрыты
4. Нажать «Показать» → связи видны, предупреждение исчезло
5. Обновить страницу → связи остаются видимыми (cookie `spoilers_ok`)

## Mobile (узкий viewport)

6. Повторить шаги 1–5 на ширине ~390px: кнопка gate доступна, списки читаемы

## Ошибки

7. `/characters/unknown-character-slug` → «Персонаж не найден» + ссылка на поиск

## SEO

8. Title вкладки: «Гарри Поттер — Книжная вселенная»
