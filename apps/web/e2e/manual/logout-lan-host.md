# Logout по LAN IP (`bd-6b7.12`)

Ручной чеклист: progressive logout должен оставаться на том же хосте, с которого открыли web (не `localhost` на телефоне).

## Предусловия

- Mac: `web` слушает `0.0.0.0:3000` (или доступен по LAN), `api` поднят
- Телефон в той же Wi‑Fi сети; узнать IP Mac (`ipconfig getifaddr en0` и т.п.), напр. `192.168.1.71`

## Сценарий

1. На телефоне открыть `http://<LAN-IP>:3000`, войти
2. Профиль / `/library` → тап **Выйти**
3. Ожидание: адресная строка `http://<LAN-IP>:3000/login` (тот же IP), страница логина открывается
4. Не должно: переход на `http://localhost:3000/login` → `ERR_CONNECTION_FAILED`

## Регресс (десктоп)

- [ ] На `http://localhost:3000` «Выйти» по-прежнему ведёт на `/login` того же origin
