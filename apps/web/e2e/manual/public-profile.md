# Публичный профиль (bd-cq7.5)

Ручной чеклист для человека. Агент гоняет Playwright; этот файл — exploratory.

## Перед проверкой

- API `:8000` и web `:3000` подняты.
- Seed-книга `garri-potter-filosofskiy-kamen` доступна.
- Зарегистрированный user с книгой в коллекции.

## Сценарии

1. Гость (без cookies) → `/u/{slug}`: коллекция (статус/оценка/теги), полки; **без** блока «Цель на год» (тумблер ещё не реализован / showOnProfile=false).
2. Клик по книге → `/u/{slug}/books/{workSlug}`: статус, оценка, теги владельца; ссылка «Страница в каталоге».
3. Несуществующий slug → «Профиль не найден.»
4. Книга не в коллекции → «Книга не найдена в коллекции.»
5. PRIVATE заметки (когда появятся в bd-sf4) — не видны на профиле и на странице книги.

## UI

- Baskerville / `font-sans`; Tailwind + shadcn Card.
- Mobile + desktop: контент не обрезан tab-bar.
