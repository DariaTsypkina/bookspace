# Порядок чтения (bd-azl.3) — ручной чеклист

Стенд: web `http://localhost:3000`, api `http://localhost:8000`.  
Сиды: серия `garri-potter`, книги с `positionInSeries` 1 и 2.

## Desktop

1. Открыть `/series/garri-potter` без cookie `spoilers_ok` (и без localStorage).
2. Видны блок **Книги** (инвентарь, «книга N») и заголовок **Порядок чтения**.
3. Вместо шагов — gate «Могут быть спойлеры» / «Показать».
4. Нажать **Показать** → появляются **Шаг 1**, **Шаг 2** с названиями книг (не типы связей).
5. Ссылка шага ведёт на `/books/...`.
6. Открыть `/books/garri-potter-filosofskiy-kamen` без согласия → один gate; после **Показать** видны и **Связи** (тип «Продолжение»), и **Порядок чтения** (Шаг 1 / Шаг 2) — блоки разные.

## Mobile (~390px)

1. Повторить п.1–6; список шагов читается, кнопки/ссылки нажимаются пальцем.

## Регресс

- Cookie `spoilers_ok=1` → порядок сразу открыт на серии и книге.
- Страница серии не ломается при отсутствии порядка (пустой `readingOrder` — блок скрыт).
