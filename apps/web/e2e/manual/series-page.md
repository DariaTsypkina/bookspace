# Карточка серии — ручной чеклист

Стенд: API + web после `pnpm --filter api prisma:seed`.

## Гость

- [ ] `/series/garri-potter` — имя «Гарри Поттер», оригинальное «Harry Potter»
- [ ] Секция «Книги»: «Гарри Поттер и философский камень», подпись «книга 1» (и год, если есть)
- [ ] Ссылка на книгу ведёт на `/books/garri-potter-filosofskiy-kamen`
- [ ] Title вкладки: «Гарри Поттер — Книжная вселенная»
- [ ] `/series/unknown-slug` — «Серия не найдена»
- [ ] С карточки книги ссылка на серию ведёт на `/series/garri-potter`
- [ ] Страница открывается без входа (гость)

## Mobile (375px)

- [ ] Название серии и список книг читаемы без горизонтального скролла
