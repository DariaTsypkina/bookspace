# Manual: UI typography form controls (Baskerville) — bd-p3l

## Предусловия

- `web` на :3000, `api` на :8000

## Чеклист

1. Открыть `/login` → DevTools → Computed на `input[type=email]`: `font-family` содержит **Baskerville**
2. На submit-кнопке «Войти»: computed `font-family` содержит **Baskerville**
3. Body / h1 «Вход» без регрессии — тоже Baskerville
4. Mobile + desktop: поля и кнопки читаемы, layout без сдвигов
