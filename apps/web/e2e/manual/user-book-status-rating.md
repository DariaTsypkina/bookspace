# Статус и оценка книги (bd-cq7.1)

Стенд: Postgres + Redis, `pnpm --filter api prisma migrate deploy`, `pnpm --filter api prisma:seed`, api `:8000` + web `:3000`.

## Авторизованный USER

- [ ] Открыть `/books/garri-potter-filosofskiy-kamen`
- [ ] Секция «В моей библиотеке»: выбрать статус (Хочу / Читаю / Прочитано / Заброшено), оценку 1–10, «Сохранить»
- [ ] Увидеть «Статус и оценка сохранены»
- [ ] Открыть `/u/<свой-slug>` — книга в списке со статусом и оценкой

## Гость

- [ ] На странице книги — «Войдите, чтобы поставить статус и оценку»
- [ ] `/u/<slug-с-книгами>` без входа показывает статусы/оценки
- [ ] Несуществующий `/u/…` — «Профиль не найден»

## Ошибки

- [ ] Оценка 0 или 11 на форме /library — клиентская валидация или 400 от API
- [ ] Несуществующий слаг на `/library` → «Произведение не найдено»

## Роли

- [ ] USER и ADMIN могут сохранять статус своей коллекции
