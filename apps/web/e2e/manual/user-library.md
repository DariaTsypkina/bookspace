# Моя библиотека (bd-cq7.4)

Ручной чеклист для человека. Агент гоняет Playwright; этот файл — exploratory.

## Перед проверкой

- API `:8000` и web `:3000` подняты.
- Seed-книга `garri-potter-filosofskiy-kamen` доступна.

## Сценарии

1. Гость → `/library`: заголовок «Моя библиотека», ссылки «Мои полки» / «Цель на год», предложение войти для коллекции (страница не пустая).
2. Войти → `/library`: empty state коллекции; в поле «Книга (название или slug)» ввести «Гарри Поттер и философский камень», выбрать подсказку и сохранить со статусом «Читаю» → книга в «Список книг».
3. Проверить fallback: ввести slug `garri-potter-filosofskiy-kamen` вручную (без выбора подсказки) → сохранение работает.
4. Фильтры: «Хочу прочитать» → пусто; «Читаю» → книга видна; «Все» → книга видна.
5. Ссылка «Мои полки» → `/library/shelves`.
6. Ссылка «Цель на год» → placeholder `/library/goal` (CRUD цели — эпик bd-sf4).
7. Mobile + desktop: фильтры и список не обрезаны tab-bar.

## UI

- Baskerville / `font-sans` на кнопках фильтров и формах.
- Без legacy `library-stub`.
