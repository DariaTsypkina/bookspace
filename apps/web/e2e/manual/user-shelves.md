# Пользовательские полки (bd-cq7.2)

Ручной чеклист для человека. Агент гоняет Playwright; этот файл — exploratory.

## Перед проверкой

- API `:8000` и web `:3000` подняты; Postgres с миграцией Shelf.
- Seed-книга `garri-potter-filosofskiy-kamen` доступна.

## Сценарии

1. Зарегистрироваться / войти → `/library` → ссылка «Мои полки».
2. `/library/shelves` → создать полку «Любимое» → открыть → empty state.
3. Добавить книгу в коллекцию через название (подсказка «Гарри Поттер и философский камень») → на полке ввести название, выбрать подсказку и добавить книгу в список.
4. Проверить fallback на полке: ввести slug `garri-potter-filosofskiy-kamen` вручную (без подсказки) → добавление работает.
5. Удалить полку → книга остаётся в коллекции (статус на `/books/...`).
6. Гостем открыть `/u/{slug}` → видна полка → открыть публичную страницу полки.
7. Гость на `/library/shelves` → предложение войти.

## UI

- Baskerville / `font-sans` на формах и кнопках.
- Mobile + desktop viewport без обрезания tab-bar.
