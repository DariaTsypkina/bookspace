# Теги пользователя (bd-cq7.3)

Ручной чеклист для человека. Агент гоняет Playwright; этот файл — exploratory.

## Перед проверкой

- API `:8000` и web `:3000` подняты; Postgres с миграцией Tag/UserBookTag.
- Seed-книга `garri-potter-filosofskiy-kamen` доступна.

## Сценарии

1. Зарегистрироваться / войти → `/books/garri-potter-filosofskiy-kamen`.
2. Сохранить статус в «В моей библиотеке».
3. В блоке «Теги» ввести имя (например «фэнтези») → «Назначить тег» → тег в списке.
4. Снять тег кнопкой × → список обновляется.
5. Гостем открыть `/u/{slug}` → у книги видно «Теги: …».
6. Гость на странице книги → предложение войти в блоке тегов.

## UI

- Baskerville / `font-sans` на формах и кнопках.
- Теги публичны (как коллекция), не путать с приватностью заметок.
- Mobile + desktop viewport без обрезания tab-bar.
