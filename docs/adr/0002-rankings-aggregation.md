# ADR 0002: Формула агрегации рейтингов MVP

- **Статус:** accepted
- **Дата:** 2026-07-15

## Контекст

Нужны «объективные» публичные топы из внешних списков без показа источников пользователю.

## Решение

- Только внешние `ExternalRankingSource`; пользовательские оценки не смешиваем в MVP.
- Score = сумма `weight × points(position)`; mention без позиции — фиксированные очки.
- Веса стартуют с 1.0, тюнинг в админке.
- Автопубликация Ranking; lock защищает ручные ranks.

## Последствия

Прозрачная админ-отладка через `AggregatedScore.details`. Смена формулы или включение user ratings — новый ADR.
