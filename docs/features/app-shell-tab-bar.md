# App shell и tab-bar

## Цель

Мобильная оболочка с нижней навигацией и единым layout.

## Акторы

Гость, user.

## User flow

1. Видеть tab-bar: Главная · Поиск · Рейтинги · Подборки · Профиль
2. Переключать разделы
3. Admin не в tab-bar

## Данные

Нет отдельных таблиц; клиентский layout.

## API / jobs

Next layouts.

## Края и ошибки

Профиль у гостя ведёт на login. Desktop — та же IA.  
«Войти»/«Выйти» не в tab-bar: гость входит через Профиль→`/login`; выход — `LogoutButton` на `/library` и `/u/[slug]`.

## Критерии приёмки

- [ ] Пять пунктов tab-bar на mobile
- [ ] Активный таб подсвечен
- [ ] `/admin` вне tab-bar
- [ ] Auth-кнопки не в меню (профиль/библиотека)
