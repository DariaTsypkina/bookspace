# Рекомендации на карточке книги

## Цель

Блок «может быть интересно» на `/books/[slug]`, отдельно от ContextReading.

## Акторы

Гость, user.

## User flow

1. Открыть книгу
2. Увидеть рекомендации
3. Перейти к другой книге

## Данные

Эвристики поверх каталога/рейтингов; см. recommendations-heuristics.

## API / jobs

Синхронный compute/read endpoint.

## Края и ошибки

Мало сигналов — меньше карточек. Не подменять ContextReading.

## Критерии приёмки

- [ ] Блок отделён от «Для понимания»
- [ ] Гость получает рекомендации без логина
