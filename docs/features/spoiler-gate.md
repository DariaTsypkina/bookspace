# Spoiler gate

## Цель

Мягкое предупреждение о спойлерах с запоминанием согласия.

## Акторы

Гость, user.

## User flow

1. Встретить спойлерный блок
2. Увидеть предупреждение «Могут быть спойлеры»
3. Подтвердить → контент открыт

## Данные

Cookie `spoilers_ok=1` (~30 дней), path `/`, SameSite=Lax.

## API / jobs

Только клиентский UX; сервер может отдавать данные, UI прячет до confirm (или режет поля — на усмотрение реализации, UX важнее).

## Края и ошибки

Без blur по статусу прочитанного. Истечение cookie → снова gate.

## Критерии приёмки

- [ ] До согласия спойлерный контент не раскрыт
- [ ] После согласия открыт полностью
- [ ] Согласие живёт ~30 дней
