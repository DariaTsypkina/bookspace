# Моя библиотека

## Цель

Кабинет `/library`: фильтры по статусу, доступ к полкам и цели.

## Акторы

User (авторизован).

## User flow

1. Открыть `/library`
2. Фильтровать по статусу
3. Перейти к полкам/цели/настройкам

## Данные

UserBook и связанные сущности владельца.

## API / jobs

Authenticated list endpoints.

## Края и ошибки

Гость → редирект на login.

## Критерии приёмки

- [x] Владелец видит всю свою коллекцию
- [x] Фильтры статусов работают
