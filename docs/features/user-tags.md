# Теги пользователя

## Цель

Тегировать книги в своей коллекции.

## Акторы

User; теги видны в рамках публичной коллекции.

## User flow

1. Назначить тег UserBook
2. Фильтровать/видеть теги в библиотеке и на профиле

## Данные

Tag / UserBookTag (или эквивалент в схеме).

## API / jobs

CRUD tags owner-only; public read.

## Края и ошибки

Приватность как у коллекции (публичны); не путать с note visibility.

## Критерии приёмки

- [x] Теги назначаются на книгу пользователя
- [x] Отображаются в публичной коллекции
