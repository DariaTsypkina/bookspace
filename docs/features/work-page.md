# Карточка произведения

## Цель

Показать каноническую книгу: метаданные, авторы, серия (ссылка), издания/переводы.

## Акторы

Гость, user (просмотр); мутации коллекции — отдельно.

## User flow

1. Открыть `/books/[slug]`
2. Увидеть titleRu, авторов, год, ссылку на серию
3. Раскрыть секцию изданий/переводов

## Данные

Work PUBLISHED, WorkAuthor, WorkSeries, Edition.

## API / jobs

GET work by slug (+ editions).

## Края и ошибки

404 на неизвестный slug. Секции relations/context/recommendations — другие фичи.

## Критерии приёмки

- [ ] Страница отдаёт RU-название и авторов
- [ ] Секция изданий отображает язык/переводчика/ISBN при наличии
- [ ] DRAFT не доступен гостю
