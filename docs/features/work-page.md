# Карточка произведения

## Цель

Показать каноническую книгу: метаданные, аннотацию (краткое содержание), авторов, серию (ссылка), издания/переводы.

## Акторы

Гость, user (просмотр); мутации коллекции — отдельно.

## User flow

1. Открыть `/books/[slug]`
2. Увидеть titleRu, авторов, год, ссылку на серию
3. При наличии `descriptionRu` — секцию «Аннотация»
4. Раскрыть секцию изданий/переводов

## Данные

Work PUBLISHED (`titleRu`, `descriptionRu?`, …), WorkAuthor, WorkSeries, Edition.

## API / jobs

GET work by slug (+ editions, `descriptionRu` при непустом значении).

## Края и ошибки

404 на неизвестный slug / DRAFT. Пустой/`null` `descriptionRu` — секция аннотации не рендерится. Секции relations/context/recommendations — другие фичи. Spoiler gate на аннотацию не распространяется.

## Критерии приёмки

- [ ] Страница отдаёт RU-название и авторов
- [ ] При непустом `descriptionRu` виден блок «Аннотация» на русском
- [ ] При пустом/отсутствующем `descriptionRu` секция не рендерится
- [ ] Секция изданий отображает язык/переводчика/ISBN при наличии
- [ ] DRAFT не доступен гостю
